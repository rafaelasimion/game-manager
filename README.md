# ⚔️ Mini RPG Battle

Um jogo simples de RPG em desenvolvimento, focado em batalhas por turnos e personagens estilizados.


**[Jogar Game Manager](https://game-manager-six.vercel.app/)**


### 🎮 Sobre o projeto

O **Mini RPG Battle** é um projeto de estudo que simula um sistema de combate entre personagens, com mecânicas simples de ataque, defesa e habilidades especiais.



### 🚀 Tecnologias utilizadas

- JavaScript
- Next.js
- CSS
